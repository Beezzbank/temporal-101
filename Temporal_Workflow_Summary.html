ขั้นตอนที่ 1

ส่งคำสั่งซื้อผ่าน REST API

คำขอจาก Client

POST /webhooks/orders

{
  "order_id": "ORD-001",
  "customer": "Alice"
}

ข้อมูลไม่ครบหรือชนิดไม่ถูกต้องจะได้รับ HTTP 400

Webhook API → Temporal

API ตรวจสอบข้อมูล แล้วเริ่ม OrderWorkflow โดยส่ง order_id และ customer เป็น Input

HTTP 202 หมายถึงรับคำขอเริ่ม Workflow แล้ว

04 / 09

ขั้นตอนที่ 2

เริ่ม Workflow ด้วย ID ที่คงที่

Workflow Type

OrderWorkflow ประมวลผลข้อมูลคำสั่งซื้อ

Workflow ID

order-ORD-001 ใช้ระบุ Order แต่ละรายการ

Task Queue

hello-task-queue เป็นคิวที่ Worker ใช้รับงาน

ใช้ order-{order_id} เป็น Workflow IDส่งคำขอเดิมซ้ำจะไม่สร้าง Workflow ใหม่สำหรับ Order เดิม
05 / 09

ขั้นตอนที่ 3

Temporal จัดการ Task และประวัติ

Temporal Server

รับคำขอจาก API บันทึกสถานะและประวัติ Workflow แล้วสร้าง Task ลงใน hello-task-queue

Durable Storage

PostgreSQL เก็บสถานะและประวัติ Workflow

Elasticsearch เก็บข้อมูล Visibility สำหรับค้นหา

Temporal Worker

เชื่อมต่อกับ Server และ Poll hello-task-queue เพื่อรับ OrderWorkflow ไปประมวลผล

Temporal เก็บประวัติ Workflow ให้ติดตามสถานะและตรวจสอบการทำงานได้

07 / 09

กรณีผิดพลาด

ตรวจสอบคำขอและผลจาก Temporal

ข้อมูลไม่ถูกต้อง

ถ้าไม่มี order_id หรือ customer ที่เป็นข้อความ API ตอบ HTTP 400

Workflow เริ่มแล้ว

API ตอบ HTTP 202 พร้อม Workflow ID เดิม เพื่อให้ Client ใช้ติดตามงานได้
