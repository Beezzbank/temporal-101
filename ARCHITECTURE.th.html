สถาปัตยกรรม Temporal บน Kubernetes สำหรับ Lab

Lab นี้รัน Temporal บน Kubernetes โดยใช้ PostgreSQL สำหรับเก็บสถานะและประวัติ Workflow, Elasticsearch สำหรับข้อมูล Visibility และ Worker Pod สำหรับประมวลผล Workflow และ Activity

ลำดับการทำงาน

  1. ผู้ใช้เริ่ม GreetingWorkflow หรือ FailingWorkflow ผ่าน Temporal CLI
  2. Temporal Frontend Service ส่งคำขอไปยัง Temporal Server
  3. Temporal Server เก็บสถานะและประวัติ Workflow ใน PostgreSQL
  4. Temporal Server ส่งข้อมูล Visibility ไปยัง Elasticsearch
  5. Worker Pod ดึงงานจาก Task Queue ชื่อ hello-task-queue
  6. GreetingWorkflow ทำงานสำเร็จ ส่วน FailingWorkflow สร้างข้อผิดพลาดโดยตั้งใจ
  7. ผู้ใช้เปิด Temporal UI เพื่อดูประวัติ Workflow และข้อผิดพลาด

คำสั่งสำหรับทดสอบ

kubectl apply -f files\50-temporal-worker.yaml
kubectl -n temporal rollout status deployment/temporal-worker

kubectl -n temporal exec -it deployment/temporal-admin-tools -- temporal workflow start --namespace default --task-queue hello-task-queue --type GreetingWorkflow --input '"Temporal"'

kubectl -n temporal exec -it deployment/temporal-admin-tools -- temporal workflow start --namespace default --task-queue hello-task-queue --type FailingWorkflow --input '"testing worker error"'

kubectl -n temporal port-forward service/temporal-ui 8080:8080

จากนั้นเปิด http://localhost:8080 ในเว็บเบราว์เซอร์
