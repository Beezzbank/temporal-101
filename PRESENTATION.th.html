05 / 10
การประมวลผล

Temporal Worker ทำอะไร?

1. รับ Workflow Task

Worker Poll งานจาก Task Queue ที่ Temporal Server จัดเตรียมไว้

2. เรียก Activity

OrderWorkflow เรียก process_order พร้อมข้อมูล Order

3. ส่งผลกลับ

Activity คืนข้อความผลลัพธ์กลับไปยัง Temporal

4. บันทึกประวัติ

Temporal บันทึกเหตุการณ์และสถานะเพื่อให้ตรวจสอบย้อนหลัง

ทำไมจึงใช้ Kafka ร่วมกับ Temporal?

แยกส่วนชัดเจน

Kafka รับผิดชอบการส่ง Event ส่วน Temporal รับผิดชอบ Business Process

ทนต่อความผิดพลาด

Event ถูกพักไว้ใน Kafka และ Workflow มีสถานะให้ติดตาม

ประมวลผลแบบไม่บล็อก

API ตอบเร็ว ไม่ต้องรอการทำงานทั้งหมด

ตรวจสอบย้อนหลัง

ดูได้ว่า Event และ Workflow ผ่านขั้นตอนใดบ้าง
